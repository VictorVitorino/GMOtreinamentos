# GMO Treinamentos — Vídeo de abertura

Repositório para o vídeo de até **2 minutos**, **Do Ford T ao carro voador**, com humor, narrativa histórica e participação-surpresa dos integrantes do treinamento. Objetivo: mostrar indiretamente por que a **Gestão da Mudança** importa para a adoção de inovações.

## Documento principal — versão aprovada
**[Abrir o storytelling oficial para Claude](storytelling/BRIEFING_CLAUDE.md)**

Esta é a versão **v2 — a turma invade a história**: participantes entram inesperadamente em diferentes épocas como pequenos easter eggs visuais, com rostos aplicados em corpos estilizados. O conceito substitui o roteiro anterior que concentrava a turma no trecho futurista.

## Organização
- `storytelling/`: narrativa aprovada, roteiro por cenas, orientações de legendagem.
- `videos-referencia/`: vídeos para orientar composição, cortes, ritmo e estética.
- `imagens/`: referências históricas e de composição; participantes e respectivos arquivos após autorização.

**Importante:** a existência de um catálogo/README **não indica que os MP4s e fotos foram enviados**. Verificar efetivamente cada arquivo. O repositório está público: não adicionar imagens particulares ou e-mails de participantes sem permissão.

**Precisão:** Ford T não foi o primeiro carro; imagens de veículo voador em uso cotidiano são hipótese visual, não prova de comercialização do Roadster.
